Make a key for this phone

  1. Add this page to your Home Screen first (Share → Add to Home Screen) and open it from there. The Home Screen app keeps its own storage, so paste the key there.
  2. Open GitHub → new fine-grained token.
  3. Name it “Phone editor”. Pick an expiration (a year is fine).
  4. Repository access: Only select repositories → website-source (the private repo with the site's source).
  5. Permissions → Repository permissions: Contents: Read and write. Optionally Actions: Read-only so the app can tell you when the site is live.
  6. Generate, copy, and paste it below.

The key stays on this phone only. If you lose the phone, delete the token on GitHub and it stops working instantly.
